# Yady - Group Management App

Yady is a mobile application designed to help users manage their time and exchange informations. It is still in development. It's built with **Kotlin**, **Jetpack Compose**, and uses **Firestore** to store and manage groups.

## Current Features:
- **Create a Group**: Users can create a new group by providing a group name and inviting users.
- **Join a Group**: Users can join an existing group by searching for it or entering an invite code.


## Tech Stack:
- **Kotlin**: The programming language used.
- **Jetpack Compose**: For creating the UI.
- **Firebase**: For backend services, including Firestore to store data.


### Prerequisites:
- **Android Studio** (or any IDE that supports Kotlin development)
- Firebase Project linked to the app
- `google-services.json` file in the `app/` folder (Firebase configuration)
